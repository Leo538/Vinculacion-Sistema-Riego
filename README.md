# IoT Weather Dashboard

Proyecto de **monitoreo y riego inteligente** con sensores IoT: dashboard en el frontend y API en el backend (en preparación).

## Estructura

| Carpeta     | Descripción                         |
|------------|-------------------------------------|
| `frontend` | Aplicación **Next.js** (dashboard)  |
| `backend`  | API / servicios (pendiente)         |

## Requisitos

- **Node.js** 18+ (frontend)

## Desarrollo (frontend)

```bash
cd frontend
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Build (frontend)

```bash
cd frontend
npm run build
npm start
```
